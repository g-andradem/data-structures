# Sorting Algorithms

Academic project developed for the Data Structures course.

The project implements different sorting algorithms in C and uses them to arrange numbers in **ascending and descending order**.

## Objective

The main goal was to implement and compare different sorting methods while studying their behavior and complexity.

## Algorithms

The project contains implementations of approximately 12 different sorting algorithms.

Each algorithm can be used to sort a set of numbers in ascending or descending order.

## Technologies

* C
* Sorting Algorithms
* Data Structures
