# Doubly Linked List

A simple diary application developed as an academic project for the Data Structures course.

The main goal of the project was to implement and use a **doubly linked list** in C.

## Features

* Add diary entries
* Remove entries
* Search entries
* Navigate through the list
* Manage diary data using a doubly linked structure

## Data Structure

Each node contains information about a diary entry and pointers to the previous and next nodes.

```text
NULL <- [Entry] <-> [Entry] <-> [Entry] -> NULL
```

## Technologies

* C
* Doubly Linked List
